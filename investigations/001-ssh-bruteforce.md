# Investigation 001 — SSH Brute-Force Simulation

> Status: In progress

## Objective

Determine what telemetry was generated when Hydra attempted to brute-force SSH authentication against the Windows domain controller, identify which telemetry was useful for investigation, and identify gaps in the current Wazuh configuration.

## Attack

Tool: Hydra

Target: Windows Server 2022 Domain Controller

Protocol: SSH

## Initial Observation

The Wazuh dashboard displayed a large amount of Windows
authentication telemetry, including repeated successful
logon events.

Further investigation is required to determine which telemetry
was generated by the attack and which events represent normal
Windows activity.
